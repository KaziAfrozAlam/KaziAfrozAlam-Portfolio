# Kazi Afroz Alam — AI Engineering Portfolio

A cinematic, performance-minded portfolio for Kazi Afroz Alam, positioned around backend AI engineering, retrieval, embeddings, ML systems and cloud deployment.

## Stack

Next.js · TypeScript · React Three Fiber · Three.js · Motion · Lucide React · Netlify Forms

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

The project is designed for Netlify deployment. Personal links and canonical content should be maintained from the site configuration/data layer. Add the authoritative CV PDF at `public/resume/Kazi-Afroz-Alam-Resume.pdf` before production launch.

## Custom domain

The site does not depend on the Netlify hostname. Point `kaziafrozalam.flyrank.ai` to the Netlify site at the DNS layer; the application itself does not need a rebuild for that domain change.

See `DNS.md` for the request flow and DNS/CNAME explanation.
